# 合同库统计工具

`get_contract_library_statistics` 一次返回合同规模、类型分布、审核人分布、注意事项及关联覆盖情况。已通过统一注册表接入主循环，执行仍经过 FIFO 管理；返回 `ordinary`，SSE 使用默认 `thinking`。不使用子 Agent、向量检索、结果池或分页。

---

## 参数与使用

参数定义、工具描述与渲染器位于 `tool/contract_statistics.py` 的 `GetContractLibraryStatisticsArguments`。

| 参数 | 类型 | 规则 |
| --- | --- | --- |
| start_time | 可选带时区日期时间 | 入库时间下界，包含该时刻；省略或 null 为不限。 |
| end_time | 可选带时区日期时间 | 入库时间上界，不包含该时刻；省略或 null 为不限。 |

两个参数均省略时统计全库成功入库合同。只提供一个参数时为单侧范围。同时提供时起点必须早于终点。拒绝无时区时间、数值时间戳和额外字段，错误通过统一工具参数反馈处理。

例如统计北京时间九月入库合同：

```json
{"start_time":"2026-09-01T00:00:00+08:00","end_time":"2026-10-01T00:00:00+08:00"}
```

## 统计口径

- 仅统计 SQLite 中 `status=ready` 的合同。日期转为带时区 datetime 比较，保留微秒边界，兼容存储中的不同时区偏移。
- 类别按合同与类别的唯一映射计数；占比为类别合同数 / 范围内合同总数。同一合同可以属于多个类别，合计可能超过 100%；未归类合同单独计数。
- 审核人按元数据中的名称分组；结果按数量降序、名称升序稳定排列。
- 注意事项为范围内合同当前的全部注意事项，统计总条数及有注意事项的合同数；不按备注创建时间再次过滤，不将备注数量解释为风险数量。
- 关系至少一端属于范围内合同，两端均属于本次 SQLite 快照中成功入库的合同。按关系 ID 去重；关联覆盖只统计范围内合同，范围外的邻居不增加覆盖数量。
- 统计时点表示本次查询开始时间，不提供历史时刻状态重建。SQLite 各项使用一个读事务；Neo4j 随后读取，不承诺跨数据库原子快照。
- 精确读取符合范围的数据，不使用 Top K 或相似度候选列表，不静默截断统计。

## 结果与失败边界

成功回执仅包含 `status=success` 和可读统计数据 `content`，不重复返回结构化 `statistics`，不附加统计口径说明、风险提醒或技术提示。统计包含起止时间、统计时点、合同总数、类别及占比、审核人、注意事项、关系数量与有无关联的合同数量。内部候选 ID 列表不回传模型。

空集合返回零计数和空分布，不请求 Neo4j。SQLite 故障使工具返回失败，不能解读为零合同。仅图数据库故障或未注入关系服务时，返回已完成的 SQLite 统计、`status=partial`，正文仅标注“关系统计：不可用”。取消按异步取消语义传播。

## 实现与验证

SQLite 统计由 `SQLiteContractMetadataStore.library_statistics` 提供；图统计经 `ContractRelationService.statistics` 调用 `ContractGraphStore.statistics`。工具在线程中读取 SQLite，异步读取图数据库。主循环在合同元数据服务可用时注册工具，无新增配置。

`tests/test_contract_statistics_tool.py` 覆盖全库、单双侧时间、时区与微秒边界、多类别、状态过滤、备注去重覆盖、空集合、部分失败、参数描述及主循环注册执行。真实开发 SQLite/Neo4j 的只读检查已执行；模型自主选择工具尚未作为本次验证内容。
