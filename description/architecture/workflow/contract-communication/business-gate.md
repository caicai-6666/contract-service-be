# 业务门禁子图

> **当前状态：** 仅完成子图初始化，调用始终返回 `status: not_implemented`，不代表任何业务校验通过，也不能作为进入智能体的授权依据。

所属任务入口见[合同沟通智能体](readme.md)。

---

## 用途与职责

`app.agent.contract_communication.business_gate` 为用户问题、文件及任务准入条件校验准备独立子图。下文记录已确认需求；当前代码仍未实现业务输入和校验规则，也未接入现有提取、入库、路由或智能体骨架。

独立子图是内部结构，不对应前端专属阶段或卡片。对外统一报告校验进度和普通结果消息，遵循 [SSE 事件契约](../../../api/communication.md#sse-事件契约)；结构化准入结论和筛选后的文件列表仍由内部工作流管理，不从消息文本解析，也不因移除专属事件而取消校验。

| 文件 | 职责 |
| --- | --- |
| `__init__.py` | 导出状态与 `build_business_gate_subgraph()`，构建并编译子图。 |
| `state.py` | 定义 `BusinessGateSubgraphState`，当前仅含可省略的 `status` 字段。 |
| `node.py` | 提供 `initialize_business_gate`，返回新的未实现状态，不修改输入。 |

---

## 当前拓扑与接口

当前为线性初始化子图：`START → initialize_business_gate → END`，没有条件分支、模型交互或工具调用。

```python
from app.agent.contract_communication.business_gate import build_business_gate_subgraph

subgraph = build_business_gate_subgraph()
result = subgraph.invoke({})
assert result == {"status": "not_implemented"}
```

异步调用使用 `await subgraph.ainvoke({})`。构建函数每次返回独立的已编译子图；后续可按 LangGraph 节点方式嵌入父图，但本次不创建父图。

输入可使用空字典；`status` 的类型仅声明 `not_implemented`，不是正式准入结果枚举。节点每次重新写入该状态，不沿用调用方传入的状态，也不输出“允许”或“拒绝”的业务判断。该 `TypedDict` 用于子图状态声明，不是面向外部请求的运行时校验器。

## 已确认的目标规则（未实现）

### 用户相关性

- 有文字时，判断是否属于合同或业务相关问题；不相关则返回提示并终止整次流程。
- 没有文字时，直接跳过相关性判断，进入文件检查。
- 文字与文件均未提供时，提示提供输入，不启动任务。

“业务问题”的具体范围、空白文字的规范化及含糊问题的澄清方式待进一步确定；不把“未能判断”默认为“明确不相关”。

### PDF 检查

对列表中的每份文件独立执行：能否正常打开 → 能否渲染为图像 → 模型是否判定为合同。任一步不满足，将该文件从本次可用文件列表中剔除，并返回具体原因。

需要密码、文件损坏、渲染失败、模型无法可靠识别和明确不是合同，应区分反馈，不能统一称为“非合同”。文本复制乱码不等于页面无法阅读；此处基于渲染后的页面进行合同识别。

剔除是本次任务输入的筛选，不意味着删除已入库合同。不能静默跳过无法处理的页面后把整份文件当作通过。实际渲染预算、页面覆盖、合同判定证据与阈值，以及临时文件清理机制待实现阶段确定。

### 检查后的流转

| 情况 | 已确认的行为 |
| --- | --- |
| 没有上传文件，但问题相关 | 跳过文件检查，进入 `agent_core`。 |
| 文件全部通过 | 进入 `agent_core`；即使没有文字，也不强制补充问题。 |
| 部分文件被剔除 | 展示保留列表、剔除列表和原因，以本轮最终答复请求确认，结束本轮。 |
| 全部文件被剔除 | 以本轮最终答复提示重新上传，或确认不依赖这些文件继续；结束本轮，不自行进入骨架。 |
| 问题明确不相关 | 提示并终止，不继续文件检查。 |

确认问题使用 `final` 消息输出，随后发布 `turn.status: completed` 并关闭事件流。用户确认或补充后，在同一会话下创建新轮次和新事件流，不恢复原轮次。待确认材料如何关联到新输入、重新上传后的检查范围和上下文继承仍未实现；事件层现已校验最终答复与结束顺序，但不自动运行门禁。

## 依赖与边界

- 复用已有 LangGraph 和 `typing_extensions`，不增加环境变量、服务或存储依赖。
- 不读取文件、不调用模型或 Elasticsearch、不产生外部副作用。
- 实际业务门禁不能替代 API、服务层和工具执行时的认证与权限校验。
- 当前没有多轮上下文、工作区或私有审计，因此不创建占位消息和恢复状态；后续新增相关节点时必须遵循[多轮 Agent 上下文与记忆管理规范](../../../standard/agent-context-management.md)。

## 验证

初始化阶段检查子图能够编译、同步和异步调用、嵌入测试父图，以及重复或并发调用保持未实现状态且不修改输入。模型失败、工具失败和业务校验路径尚不存在，不将初始化验证视为真实门禁功能验收。
