# PDF 页面融合权重实验

> **用途：** 在不重新调用 Qwen3-VL-Embedding 的前提下，使用鲁棒性实验保存的页面向量，比较等权、首页、尾页以及首尾同时加权对多页合同召回的影响。

---

## 用途与假设

本实验只关注 `test-data` 中页数不少于 2 页的合同，固定正式 `contract-near-duplicate-v1` 指令和页面向量，变量只有合同级融合权重：

- 首页加权可能增强合同名称、主体和编号等身份信息。
- 尾页加权可能增强签章、签署日期和结算身份等身份信息。
- 首尾同时加权可能同时保留合同开头的主体信息和结尾的签章信息。
- 权重应保持温和，避免单个模板页支配整份合同；本实验固定增强页权重为 `1.5`，普通页为 `1.0`。

实验同时计算等权平均作为同批 query 的参考，不把参考组计为本次两组加权方案。

---

## 实验设计

- 样本：从鲁棒性实验同一批 9 份唯一合同中筛选 `page_count >= 2`，预计 5 份、18 页。
- query：复用鲁棒性实验中的 13 个扰动变体及其页面向量，包括缩放、非等比缩放、JPEG 降质、组合扰动和缺页。
- gallery：复用同一运行目录中的完整合同融合页面向量。
- 指令、模型、页面渲染和 query 扰动不重新生成，保证与鲁棒性实验一致。
- 检索：内存精确余弦排序，正确合同由同一 `document_id` 确定。

四种融合参考：

| 组别 | 权重规则 |
| --- | --- |
| `uniform` | 所有保留页面 `1.0`，用于同批基线。 |
| `home-1.5` | 原始物理第 1 页 `1.5`，其余保留页 `1.0`。 |
| `tail-1.5` | 原始物理最后一页 `1.5`，其余保留页 `1.0`。 |
| `both-ends-1.5` | 原始物理第 1 页和最后一页均为 `1.5`，其余保留页 `1.0`。 |

缺页时按原始物理页码判断：首页缺失时首页加权组没有被加权页面，尾页缺失时尾页加权组没有被加权页面；不将剩余页面重新标记为首页或尾页。

---

## 指标与判定

每个融合组分别按全部适用扰动和每个扰动变体统计：

- `Recall@1`、`Recall@3`、`MRR`。
- 平均和最小正负间隔。
- 平均正样本相似度、最强负样本相似度。
- 相对等权基线的 Recall 和间隔变化。

判定原则：

- 不能只看一次总体平均；若某一组提升平均值但导致某个缺页或强降质变体 Recall 下降，应视为存在鲁棒性回归。
- 若首页和尾页加权都保持 Recall 不下降，则优先选择最小正负间隔更高、最坏变体间隔更高的一组。
- 若两组差异很小，则保留等权平均，避免引入不必要的页序先验。

## 运行方式

默认读取最近一轮鲁棒性实验输出：

```bash
.venv/bin/python experiment/pdf-page-fusion-weighting/run.py
```

显式指定来源运行目录：

```bash
.venv/bin/python experiment/pdf-page-fusion-weighting/run.py \
  --source-run experiment/pdf-page-embedding-robustness/output/20260901T111326.358868Z
```

本实验只进行本地向量融合和排序，不产生远程模型请求。

## 产物说明

```text
output/<UTC 时间>/
├── manifest.json
├── result.json
└── analysis.md
```

- `manifest.json`：来源运行目录、页数筛选、四组权重规则和样本摘要。
- `result.json`：四组融合策略的全量/变体指标、逐合同排名和相对等权差异。
- `analysis.md`：人工分析记录，只追加，不由运行器生成。

当前采用策略：`tail-1.5`。该选择基于本实验中其平均正负间隔最高，且所有召回指标均保持 100%；正式工作流实现应使用相同的尾页权重规则，并升级融合版本。

---

## 局限性

- 本实验只覆盖 5 份多页合同，其中页数为 2～6 页；不能代表长合同和大量附件。
- query 页面向量来自重渲染和缺页扰动，未覆盖页序错乱、增页或页面替换。
- 首页和尾页权重只测试 `1.5`，不比较 `1.25`、`2.0` 或质量自适应权重。
- 内存精确排序不等同于 Elasticsearch HNSW 实际召回。
