# PDF 页面向量鲁棒性实验

> **用途：** 全面验证已确定的 `contract-near-duplicate-v1` 页面向量策略在等比缩放、非等比缩放、图像降质和缺页扰动下的合同级召回稳定性。

---

## 用途与假设

本实验只验证已经确定的推荐指令和等权页面融合，不比较其他指令，也不改变生产节点。假设如下：

- 等比缩放、再次栅格化和 JPEG 降质主要是视觉噪声，不应改变同一合同的第一名身份。
- 适度非等比缩放仍应保留足够的文字和版式结构，使同源合同进入 Top3。
- 缺少一页时，剩余页面仍可能保留合同身份；但缺首页、正文页和末页的影响应分别观察，不能预设同一阈值。
- 正确合同在变换后仍排第一，且与最强负样本保持正间隔，是比绝对相似度更重要的稳定性信号。

本实验不把所有扰动都判定为必须通过。对于缺页，结果用于建立退化曲线；是否放行应由后续业务阈值和 MLLM 复核共同决定。

---

## 实验设计

### 样本与 gallery

- 输入：递归读取 `data/input/test-data/**/*.pdf`。
- 源文件 SHA-256 是输入身份；完全相同的多路径只保留字典序第一条，并在 manifest 中记录排除项。
- gallery：调用生产 `AsyncPDFPreparationService`，使用当前处理版 PDF 的全部页面 PNG。
- query：从 gallery 页面 PNG 在本地生成扰动版本，保持同一合同身份；不重新请求 MLLM，不引入文本 OCR。
- 召回：所有 query 与完整 gallery 合同做内存精确余弦排序，模拟合同级 TopK 召回。

### 扰动矩阵

| 类别 | 变体 | 说明 |
| --- | --- | --- |
| 等比缩放 | `scale-0.50`、`scale-0.75`、`scale-1.25`、`scale-1.50` | 宽高同比例缩放后再编码为 PNG。 |
| 非等比缩放 | `nonuniform-wide-1.35x-0.75y`、`nonuniform-tall-0.75x-1.35y` | 分别拉宽或拉高，保持页面内容但改变宽高比。 |
| 降低质量 | `jpeg-q85`、`jpeg-q60`、`jpeg-q30` | JPEG 质量压缩后再转为 PNG，保留压缩伪影但统一请求媒体类型。 |
| 组合扰动 | `scale-0.50-jpeg-q30` | 低分辨率与强降质叠加。 |
| 缺页 | `missing-first`、`missing-middle`、`missing-last` | 仅适用于多页合同；分别删除首页、中间页或末页后融合剩余页面。 |

单页合同的缺页变体不生成，因为删除唯一页面不是可比较的“部分缺页” query；缺页变体的实际保留页码写入每项结果。

### 固定条件

- 使用正式 `contract-near-duplicate-v1` 指令和正式单页消息构造器。
- 每个请求只携带一张页面图像。
- 每页向量 L2 归一化，合同向量使用等权算术平均后再次 L2 归一化。
- 记录实际 HTTP 请求耗时与本地并发等待耗时，二者不混用。
- gallery 页面和每个 query 变体的页面向量均保存，以便后续复算不同融合权重。

## 指标与判定

每个扰动变体分别计算：

- `Recall@1`、`Recall@3`、`MRR`。
- 平均/最小正负间隔。
- 平均正样本相似度和最强负样本相似度。
- 适用合同数、完整向量数、页面请求成功率。
- 全部合同、单页合同、多页合同三个子集的同口径指标。

建议解释口径：

- 缩放和降质：重点观察是否保持 `Recall@1 = 100%`。
- 非等比缩放：重点观察 Recall@3、最小间隔和是否出现单合同严重退化。
- 缺页：重点观察随缺失位置变化的退化，不要求预先设定“必然通过”。
- `Recall@3` 只说明正确合同进入候选范围，最终重复决定仍需 MLLM。

## 运行方式

```bash
.venv/bin/python experiment/pdf-page-embedding-robustness/run.py
```

降低并发以减少远程服务压力：

```bash
.venv/bin/python experiment/pdf-page-embedding-robustness/run.py --concurrency 2
```

每次运行创建新的 UTC 目录，不覆盖既有结果。当前矩阵在 9 份唯一合同、22 页上预计产生约 279 次页面请求。

## 产物说明

```text
output/<UTC 时间>/
├── manifest.json
├── result.json
├── requests.json
├── page-embeddings.json
└── analysis.md
```

- `manifest.json`：输入去重结果、页面身份、全部扰动定义、模型配置和运行参数。
- `requests.json`：逐页成功/失败、图片哈希、变体、页面信息、排队与 HTTP 耗时、token。
- `page-embeddings.json`：成功页面的原始 4096 维向量。
- `result.json`：每个变体的全量与单页/多页召回指标、逐合同排名和退化情况。
- `analysis.md`：人工分析记录，只追加，不由运行器生成。

## 局限性

- 扰动作用于已经处理好的页面 PNG，不等同于真实用户重新上传原始 PDF 后的全部处理差异。
- 非等比缩放只覆盖两个固定方向和强度，未覆盖旋转、裁切、透视变形、拍照阴影、污损和水印。
- 缺页只删除单页，不覆盖增页、换页、页序错乱和局部页面替换。
- 候选库规模仍有限，且缺少同模板不同主体/金额/日期的困难负样本。
- 使用内存精确余弦排序，不代表 Elasticsearch HNSW 的实际召回结果。
- 当前实验只验证等权平均，不决定首页或首尾加权策略。
