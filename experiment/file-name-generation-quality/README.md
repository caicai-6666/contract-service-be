# 合同建议文件名质量实验

> **用途：** 使用一份具有精确标题的合同和一份只有粗略标题的合同，验证“页面理解 → 合同分类 → 建议命名”流程能否生成准确、友好且有辨识度的文件名主体。

---

## 用途与假设

本实验验证两个互补假设：

- 页面已有精确标题时，模型不会为了改写而丢失标题中的核心业务信息。
- 页面只有“采购合同”这类粗略标题时，模型会结合实际交易内容补充核心标的，而不是照抄泛化标题。

任一样本未生成结果、引用越界页面、生成扩展名，或未满足对应内容判定时，当前实现不能通过本次小样本验证。机器判定通过后仍需人工复核名称是否自然，关键词命中不等同于完整质量结论。

---

## 实验设计

实验固定使用以下两份样本，并按表中顺序串行执行：

| 分组 | 输入 | 页面可见标题 | 变量 |
| --- | --- | --- | --- |
| 精确标题 | `data/input/test-data/废气噪声检测合同pdf.pdf` | `深圳现象光伏科技有限公司废气和噪声检测服务合同` | 标题已经包含主体与具体服务内容 |
| 粗略标题 | `data/input/test-data/柏莱-深圳现象光伏科技有限公司0908_已签章.pdf` | `销售合同` | 标题泛化，正文标的是信号传输电路板 |

- 两份合同均复用当前生产页面准备、文档结构理解和分类子图，再调用建议文件名子图。
- 合同之间不并发，避免共享模型负载互相污染；单份合同内部保留生产分类并发行为。
- 不提供文件原名作为命名提示，避免输入路径泄漏答案。
- 不设置缓存盐，保留当前生产请求的前缀缓存行为。
- 不运行 Core、Clause、Retrieval 和 Elasticsearch 入库，避免无关流程影响本次结论。

本实验没有旧提示词或其他模型对照组，是对当前实现的双样本冒烟与质量检查。

---

## 指标与判定

| 指标 | 计算口径 | 通过条件 |
| --- | --- | --- |
| 生成成功 | `suggested_file_name.status` | 两份均为 `generated` |
| 文件名合法 | 扩展名、非法字符、首尾句点与长度检查 | 两份均合法 |
| 证据有效 | 每条证据的物理页码位于合同页数内 | 两份均有效 |
| 精确标题信息保留 | 建议名称包含页面标题的核心服务词 | 同时包含“废气”“噪声”“检测” |
| 粗略标题细化 | 建议名称不等于泛化标题，且包含实际标的词 | 不等于“销售合同”，并包含“信号传输电路板”“电路板”或“PCB”之一 |

程序把以上五项全部满足记为 `machine_check_passed=true`。人工分析还会查看页面证据、分类摘要和命名理由，判断名称是否简洁自然、是否引入无证据事实；人工结论可以否决机器通过结果。

---

## 运行方式

前置条件：`contract-service-be` Conda 环境依赖已安装，`.env` 中的 MLLM 地址和凭证可用。

从项目根目录执行：

```bash
conda run -n contract-service-be --no-capture-output \
  python experiment/file-name-generation-quality/run.py
```

每次运行创建新的 UTC 时间戳目录，不覆盖历史结果。

## 产物说明

```text
output/<UTC 时间>/
├── manifest.json
├── result.json
├── samples/
│   ├── 001/
│   │   ├── response.json
│   │   └── inference-metrics.json
│   └── 002/
│       ├── response.json
│       └── inference-metrics.json
└── analysis.md
```

- `manifest.json`：输入哈希、代码状态、提示词/工具版本和去密钥模型配置。
- `result.json`：两份样本的建议名称、机器检查及推理请求汇总。
- `response.json`：不含页面图片字节和公共模型消息的结构理解、分类、命名结果及私有审计。
- `inference-metrics.json`：逐请求耗时、token 和服务端指标，不含提示词或回答正文。
- `analysis.md`：运行后追加的人工分析，只链接并解释原始产物，不改写原始结果。

---

## 局限性

- 每组只有一份样本，不能代表所有标题样式、扫描质量和合同类别。
- 没有多个模型、提示词版本或重复随机运行对照，无法估计波动和因果改进幅度。
- 关键词判定只能发现明显遗漏，不能自动验证名称是否最自然或事实是否完整准确。
- 远程模型服务负载与前缀缓存会影响耗时，性能结果仅描述本次运行条件。
- 原始产物包含测试合同中的少量业务文本，只能保留在本地忽略的实验输出目录中。
